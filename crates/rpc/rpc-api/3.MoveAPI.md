# Kanari Move VM API Guide

## Introduction

The Kanari Move VM API provides comprehensive JSON-RPC endpoints for interacting with Move modules on the Kanari blockchain. This API supports module deployment, function execution, transaction tracking, and state management.

## API Base URL

All endpoints are accessible at `http://[node-address]:[port]` (default: `http://127.0.0.1:30030`)

## Move API Usage Examples

### 1. List Modules

List all deployed Move modules with pagination and filtering:

```bash
# List first 5 modules
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "list_modules",
  "params": {
    "limit": 5,
    "offset": 0
  },
  "id": 1
}' http://127.0.0.1:30030
```

```bash
# List modules with address filter
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "list_modules",
  "params": {
    "limit": 10,
    "address_filter": "0x1"
  },
  "id": 1
}' http://127.0.0.1:30030
```

**Response:**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "modules": [
      {
        "module_id": "0x1::coin",
        "address": "0x1",
        "name": "coin",
        "bytecode_size": 4280,
        "deploy_block_height": 1024,
        "deploy_timestamp": 1635739200,
        "public_functions": ["mint", "burn", "transfer"],
        "function_count": 3
      }
    ],
    "total": 1,
    "limit": 5,
    "offset": 0
  }
}
```

## Supported Argument Types

When calling functions, use these argument type formats:

| Type | Format | Example |
|------|--------|---------|
| `address` | Hex string | `{"arg_type": "address", "value": "0x1234567890abcdef"}` |
| `u8` | Number (0-255) | `{"arg_type": "u8", "value": 42}` |
| `u64` | Number | `{"arg_type": "u64", "value": 1000000}` |
| `u128` | Number or string | `{"arg_type": "u128", "value": "123456789012345678901234567890"}` |
| `bool` | Boolean | `{"arg_type": "bool", "value": true}` |
| `string` | String | `{"arg_type": "string", "value": "Hello World"}` |
| `vector<u8>` | Hex string or string | `{"arg_type": "vector<u8>", "value": "0x48656c6c6f"}` |

## Execution Modes

### Simulation Mode (Default)
```bash
# Execute without blockchain submission
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "execute_function",
  "params": {
    "module_id": "0x1::coin",
    "function": "get_balance",
    "submit_to_blockchain": false
  },
  "id": 1
}' http://127.0.0.1:30030
```

### Blockchain Mode
```bash
# Execute and submit to blockchain
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "execute_function",
  "params": {
    "module_id": "0x1::coin", 
    "function": "transfer",
    "submit_to_blockchain": true
  },
  "id": 1
}' http://127.0.0.1:30030
```

## Rate Limits

- Read operations (list_modules, get_module, get_vm_state): 100 requests/minute
- Execute operations (execute_function): 20 requests/minute  
- Deploy operations (deploy_module): 5 requests/minute

## Security Best Practices

1. **Always estimate gas first:**
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "estimate_gas",
  "params": {...},
  "id": 1
}' http://127.0.0.1:30030
```

2. **Use simulation mode for testing:**
```bash
# Test without blockchain submission
"submit_to_blockchain": false
```

3. **Set appropriate gas budgets:**
```bash
# Use recommended gas from estimation
"gas_budget": 1020
```

4. **Validate module existence:**
```bash
# Check module exists before calling
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_module",
  "params": {"module_id": "0x1::coin"},
  "id": 1
}' http://127.0.0.1:30030
```

This comprehensive API allows full interaction with Move smart contracts on the Kanari blockchain, supporting both development and production use cases.
