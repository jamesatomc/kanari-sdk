# Kanari SDK RPC API Guide

Here are all the available API endpoints and how to call them using curl in Git Bash:

## API Base URL

All examples use `http://127.0.0.1:30030` as the default endpoint. Replace with your node's address as needed.

## 1. Blockchain Status
Get current blockchain status:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "blockchain_status",
  "params": [],
  "id": 1
}' http://192.168.1.103:30030
```

## 2. Get All Blocks
Get all blocks:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_all_blocks",
  "params": [],
  "id": 1
}' http://192.168.1.103:30030
```

## 3. Get Account
Check account details:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0", 
  "method": "get_account_details",
  "params": {
    "address": "YOUR_ACCOUNT_ADDRESS"
  },
  "id": 1
}' http://192.168.1.103:30030
```

## 4. List Accounts
Get all accounts and their balances:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "list_accounts",
  "params": [],
  "id": 1
}' http://192.168.1.103:30030
```

## 5. Transfer Tokens
Send KARI tokens (with dynamic gas fees):
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "transfer",
  "params": {
    "from": "SENDER_ADDRESS",
    "to": "RECEIVER_ADDRESS",
    "amount": 1.0,
    "password": "WALLET_PASSWORD",
    "priority_boost": 5
  },
  "id": 1
}' http://192.168.1.103:30030
```

The `priority_boost` parameter is optional and can be used to increase gas fee for faster processing.
Response includes a unique transaction ID (0x followed by 64 random hex characters) that can be used to track the transaction, along with gas fee details.

## 6. Get Wallets
List all available wallets:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_wallets",
  "params": [],
  "id": 1
}' http://192.168.1.103:30030
```

## 7. Search Transactions
Search for transactions by address with pagination:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "search_transactions",
  "params": {
    "address": "YOUR_ACCOUNT_ADDRESS",
    "limit": 10,
    "offset": 0
  },
  "id": 1
}' http://192.168.1.103:30030
```

## 8. Get Transaction by ID
Look up a transaction using its unique ID:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_transaction_by_id",
  "params": "0xTRANSACTION_ID",
  "id": 1
}' http://192.168.1.103:30030
```

The response includes transaction details including gas fees, the containing block, and current balances of both sender and receiver.

## 9. Get Gas Fee Info
Get information about current gas fee settings and network congestion:

curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_gas_fee_info",
  "params": [],
  "id": 1

## 10. Staking Operations

### 10.1 Stake Tokens
Stake KARI tokens to run a node or become a validator:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "stake_tokens",
  "params": {
    "address": "YOUR_ACCOUNT_ADDRESS",
    "amount": 200.0,
    "password": "WALLET_PASSWORD",
    "validator": true
  },
  "id": 1
}' http://192.168.1.103:30030
```

- Minimum amount for running a node: 200 KARI
- Minimum amount for becoming a validator: 32 KARI
- Setting `validator` to `true` will make the node eligible for staking rewards (0.01%)
- All staked tokens have a 24-hour lock period

### 10.2 Unstake Tokens
Withdraw your staked KARI tokens (plus rewards if a validator):
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "unstake_tokens",
  "params": {
    "address": "YOUR_ACCOUNT_ADDRESS",
    "password": "WALLET_PASSWORD"
  },
  "id": 1
}' http://192.168.1.103:30030
```

- Early unstaking (before lock period ends) will incur a 10% penalty
- Validators will receive accumulated rewards when unstaking

### 10.3 Get Staking Info
Check your staking status and rewards:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_staking_info",
  "params": ["YOUR_ACCOUNT_ADDRESS"],
  "id": 1
}' http://192.168.1.103:30030
```

### 10.4 Get Staking Statistics
Get network-wide staking information:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_staking_stats",
  "params": [],
  "id": 1
}' http://192.168.1.103:30030
```

## 11. Move VM Operations

### 11.1 List Move Modules
List all deployed Move modules:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "list_modules",
  "params": {
    "limit": 10,
    "offset": 0
  },
  "id": 1
}' http://127.0.0.1:30030
```

### 11.2 Get Module Details
Get information about a specific Move module:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_module",
  "params": {
    "module_id": "0x1::coin"
  },
  "id": 1
}' http://127.0.0.1:30030
```

### 11.3 Execute Move Function
Call a function in a deployed Move module:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "execute_function",
  "params": {
    "module_id": "0x1::coin",
    "function": "transfer",
    "args": [
      {"arg_type": "address", "value": "0x2"},
      {"arg_type": "u64", "value": 1000}
    ],
    "sender": "0x1",
    "gas_budget": 1000000,
    "submit_to_blockchain": true
  },
  "id": 1
}' http://127.0.0.1:30030
```

### 11.4 Deploy Move Module
Deploy a new Move module to the blockchain:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "deploy_module",
  "params": {
    "bytecode": "a11ceb0b03000000...",
    "sender": "0x1234567890abcdef",
    "gas_budget": 5000000
  },
  "id": 1
}' http://127.0.0.1:30030
```

### 11.5 Estimate Gas
Estimate gas costs for Move function execution:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "estimate_gas",
  "params": {
    "module_id": "0x1::coin",
    "function": "transfer",
    "args": [
      {"arg_type": "address", "value": "0x2"},
      {"arg_type": "u64", "value": 1000}
    ]
  },
  "id": 1
}' http://127.0.0.1:30030
```

### 11.6 Get VM State
Get current Move VM state and statistics:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_vm_state",
  "params": {},
  "id": 1
}' http://127.0.0.1:30030
```

### 11.7 Get Module Transactions
Get transaction history for a specific module:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_module_transactions",

```

## Placeholders
Replace these placeholders with actual values when making requests:
- `YOUR_ACCOUNT_ADDRESS`: Your wallet address
- `SENDER_ADDRESS`: Address sending tokens
- `RECEIVER_ADDRESS`: Address receiving tokens
- `WALLET_PASSWORD`: Your wallet password
- `0xTRANSACTION_ID`: Transaction ID (0x followed by 64 hex characters)

## Response Format
Successful response:
```json
{
  "jsonrpc": "2.0",
  "result": {
    // Response data specific to each endpoint
  },
  "id": 1
}
```

Error response:
```json
{
  "jsonrpc": "2.0",
  "error": {
    "code": -32000,
    "message": "Error description"
  },
  "id": 1
}
```

## Transaction Structure
Transaction objects contain the following fields:
- `id`: Unique transaction identifier (0x + 64 hex characters)
- `sender`: Address of the sender
- `receiver`: Address of the receiver
- `amount`: Amount of tokens transferred (in KA units)
- `amount_formatted`: Human-readable amount in KARI
- `gas_fee`: Dynamic gas fee for the transaction (in KA units)
- `gas_fee_formatted`: Human-readable gas fee in KARI
- `timestamp`: UNIX timestamp when the transaction was created

## Gas Fee System
Each transaction has a dynamic gas fee that is:
- Calculated based on network congestion and optional priority boost
- Deducted from the sender in addition to the transfer amount
- Sent to the gas collection address: 0x47621776628ba3a5b9baaab38e61f4c98e893e124204bc4dad52e702e2b24ea1

Gas fees range from a minimum of 0.000000002 KARI to a maximum of 0.000000050 KARI depending on network conditions.

To prioritize your transaction, you can add the optional `priority_boost` parameter when making transfers.

## Staking System

The Kanari network uses a Proof of Stake (PoS) consensus mechanism where:

- Users must stake at least 200 KARI to run a node
- Validators must stake at least 32 KARI and opt in to validation
- Validators receive a 0.01% annual reward on their staked amount
- Rewards are drawn from the token pool at address: `0x47621776628ba3a5b9baaab38e61f4c98e893e124204bc4dad52e702e2b24ea1`
- All staked tokens have a 24-hour lock period
- Early unstaking incurs a 10% penalty

## Security Note

All API endpoints must be accessed using HTTPS. HTTP requests will be rejected.
Required headers:
- Content-Type: application/json
- Accept: application/json
- X-API-Key: Your API key (if configured)

SSL certificate and private key files (cert.pem and key.pem) must be present in the working directory.

By participating in staking, validators help secure the network while earning rewards.

## Move Smart Contract Integration

The Kanari blockchain supports Move smart contracts through the Move VM. You can:

- Deploy Move modules using `deploy_module`
- Execute module functions using `execute_function` 
- Query module state and transaction history
- Estimate gas costs before execution
- Choose between simulation and blockchain execution modes

Move transactions are integrated with the main blockchain and appear in regular transaction searches with type `VM_FUNCTION_CALL` or `VM_MODULE_DEPLOYMENT`.

All Move operations support the same gas fee system as regular transactions, with dynamic pricing based on network congestion.
